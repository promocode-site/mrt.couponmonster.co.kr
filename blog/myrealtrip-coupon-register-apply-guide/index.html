마이리얼트립 할인쿠폰 등록 전에 확인할 것

여행 일정을 짜다 보면 투어, 액티비티, 숙소를 한 번에 예약하게 되는 경우가 많습니다. 이때 쿠폰을 어떻게 등록하고 적용하는지 순서를 미리 알아두면 결제 직전에 헤매지 않습니다.

쿠폰을 등록하기 전에는 먼저 예약하려는 상품이 쿠폰 사용 대상인지, 그리고 쿠폰 유효기간이 남아 있는지부터 확인하는 것이 좋습니다. 마이리얼트립 할인쿠폰은 상품 카테고리나 결제 수단에 따라 적용 조건이 다르게 걸려 있는 경우가 있어서, 등록 화면에 뜨는 안내 문구를 한 번 더 읽어보는 습관을 들이면 좋습니다.

앱과 웹 모두에서 쿠폰함 메뉴가 있는데, 로그인한 계정 기준으로 쿠폰이 쌓이기 때문에 예약 전에 로그인부터 해두는 것이 순서상 편합니다.

쿠폰 코드 등록하는 방법

코드형 쿠폰은 마이페이지의 쿠폰 등록 화면에서 코드를 직접 입력하는 방식으로 등록합니다. 입력 칸에 코드를 붙여넣을 때 앞뒤 공백이 함께 복사되면 인식이 안 되는 경우가 있으니, 코드만 정확히 입력했는지 한 번 확인해 주세요.

지금 등록해볼 수 있는 코드 몇 가지를 정리하면 다음과 같습니다.

  • LINKPRICE2000 — 0% 할인
  • LINKPRICE3000 — 0% 할인
  • LINKPRICESTAY1000 — 0% 할인
  • PACKMKTP5000 — 3% 할인

할인율과 적용 조건은 등록 시점에 다시 안내되는 값을 기준으로 하고, 위 수치는 변동될 수 있으니 등록 화면에서 최종 확인을 해보시기 바랍니다. 코드를 붙여넣기 전에 마이리얼트립 LINKPRICE2000 할인코드 받기 페이지에서 현재 유효한 코드 목록을 한 번 더 확인해두면 헛걸음을 줄일 수 있습니다.

투어·액티비티·숙소별 적용 방법

같은 쿠폰이라도 상품 카테고리마다 적용되는 방식이 조금씩 다릅니다. 투어나 입장권류는 결제 페이지에서 쿠폰 선택란이 따로 뜨는 경우가 많고, 숙소 예약은 객실을 먼저 선택한 다음 결제 단계에서 쿠폰함을 열어야 적용 가능한 쿠폰이 보이는 구조입니다.

숙소 예약에 쓸 수 있는 코드로는 LINKPRICESTAY1000, LINKPRICESTAY3000 같은 코드가 있고, 패키지 상품에는 PACKMKTP1000, PACKMKTP3000, PACKMP1000, PACKMPT3000 코드가 걸려 있는 경우가 있습니다. 상품 상세 페이지나 결제 화면에서 해당 쿠폰이 적용 가능 목록에 뜨는지 먼저 확인한 뒤 선택하는 순서로 진행하면 됩니다.

한 번에 여러 상품을 담아 결제하는 경우에는 쿠폰이 상품별로 각각 적용되는지, 전체 결제 금액에 한 번만 적용되는지도 결제 페이지 안내를 통해 확인해 두는 것이 좋습니다.

쿠폰이 적용되지 않을 때 체크리스트

등록까지는 됐는데 결제 화면에서 쿠폰이 보이지 않는다면 몇 가지를 순서대로 점검해보시기 바랍니다. 먼저 쿠폰 유효기간이 지나지 않았는지, 다음으로 예약하려는 상품이 쿠폰 적용 대상 카테고리에 속하는지를 확인합니다.

그다음으로는 최소 결제 금액 조건이나 결제 수단 제한이 걸려 있지는 않은지도 살펴봐야 합니다. 이런 조건은 쿠폰마다 다르게 붙어 있을 수 있어서, 등록 화면이나 쿠폰함 상세보기에 나오는 안내 문구를 다시 한번 읽어보는 것이 가장 확실합니다.
