기준 금액을 채울 때의 손익

  • 투어·티켓은 3,000원 차이를 비교하세요

    197,000원에 3,000원 할인을 받으면 194,000원입니다. 같은 예약에서 필요한 옵션 3,000원을 더해 200,000원이 되고 6,000원 할인이 적용되면 최종 금액은 똑같이 194,000원입니다. 추가 지출이 3,000원을 넘으면 할인액이 커져도 총지출은 늘어납니다.

  • 해외 숙소는 2,000원 차이를 비교하세요

    148,000원에서 1,000원을 빼면 147,000원입니다. 동일한 숙박 조건의 150,000원 요금에 3,000원을 빼도 147,000원입니다. 요금 차이가 2,000원일 때만 금액이 같아지므로 조식·취소 조건까지 함께 비교하세요.

계산은 한 예약에서 기준 금액을 채울 수 있을 때에만 성립합니다. 서로 다른 상품의 결제 금액이 자동 합산된다고 생각하지 마세요.

할인코드 사용방법

발급부터 결제 확인까지

  1. 할인코드 발급 버튼으로 제휴 페이지에 접속한 뒤 예약에 사용할 계정으로 로그인하세요.
  2. 해외 숙소 또는 해외 투어·티켓 중 구매할 상품에 맞는 할인쿠폰을 발급받으세요. 발급 화면에서 할인코드 등록을 요구하면 위 문자열을 그대로 입력하세요.
  3. 상품과 이용일, 인원, 객실 또는 옵션을 선택하고 결제 화면으로 이동하세요. 최소 금액은 선택을 마친 예약 기준으로 확인하세요.
  4. 쿠폰·할인 항목에서 발급받은 할인쿠폰을 선택하세요. 문자열을 입력하는 칸이 제공되는 화면에서는 할인코드를 입력한 뒤 적용 결과를 확인하세요.
  5. 결제수단을 선택하고 최종 결제 금액을 확인하세요. 인원·요금·결제수단을 바꿨다면 할인 선택이 유지되는지 다시 확인하세요.
  6. 결제를 마친 뒤 예약 내역의 할인액과 실제 결제액을 대조하세요. 결제 승인과 예약 확정 상태도 각각 확인하세요.

상품과 접속 화면에 따른 확인 위치

투어·티켓
날짜와 인원·옵션을 정한 뒤 나오는 주문·결제 단계에서 할인쿠폰 선택 여부를 확인하세요. 검색 목록의 표시 가격만으로 최소 금액을 판단하지 마세요.
해외 숙소
객실과 요금제를 선택한 결제 단계에서 숙소용 할인쿠폰을 확인하세요. 현장 결제 비용은 온라인 할인액 계산과 나누어 확인하세요.
항공권
위 5종은 항공권용으로 안내된 할인코드가 아닙니다. 항공권 결제 화면에 위 할인코드를 입력하는 방식으로 진행하지 마세요.
PC·모바일 웹·앱
화면별로 메뉴 위치와 명칭이 달라질 수 있습니다. 제휴 페이지에서 발급을 마친 계정과 결제하는 계정이 같은지 먼저 확인하세요. 앱으로 전환했다면 쿠폰 목록에 발급 내역이 있는지 확인하세요.

할인액으로 진행 상태 확인

  • 20만원 투어·티켓 결제 예시

    할인 인정 금액이 200,000원이고 6,000원 할인쿠폰만 적용했다면 194,000원이 됩니다. 결제액이 197,000원이라면 3,000원 할인쿠폰이 선택됐는지 확인하세요.

  • 15만원 해외 숙소 결제 예시

    150,000원에 숙소용 3,000원 할인쿠폰만 적용하면 147,000원입니다. 149,000원이 표시된다면 1,000원 할인쿠폰이 선택됐는지 확인하세요.

할인쿠폰이 보이지 않을 때의 확인 순서

발급 계정 → 상품 종류 → 최소 금액 → 사용기한 → 발급·사용 이력 순서로 확인하세요. 투어·티켓이 149,000원이라면 3,000원 할인쿠폰의 150,000원 조건을 충족하지 못합니다. 금액이 충분해도 쿠폰 목록에 사용할 수 있다고 표시되지 않으면 할인 적용을 전제로 결제하지 마세요.

할인코드 참고사항

할인 인정 금액과 실제 지출

이 페이지의 할인율은 할인액을 할인 전 금액으로 나누어 계산합니다. 세금·수수료·현장 납부액이 최소 결제 금액에 포함되는지는 상품 결제 화면의 적용 결과로 확인하세요. 표의 계산에는 별도 수수료와 현장 납부액을 더하지 않았습니다.

총 여행비와 할인 기준은 다를 수 있습니다. 온라인 결제 200,000원에 6,000원 할인을 받고 현장에서 20,000원을 별도로 낸다고 가정하면 총지출은 214,000원입니다. 할인 전 총비용 220,000원 기준 체감 할인율은 약 2.73%입니다.

할인코드·쿠폰·결제 혜택의 중복

위 할인코드 + 페이 할인페이 행사 약관과 결제 화면의 동시 적용 결과 확인 필요연결 카드·잔액 결제 조건과 할인 표시를 확인하세요.
카드 할인 + 페이 할인두 행사의 중복 허용 여부 확인 필요페이에 카드를 연결한 사실만으로 두 할인을 합산하지 마세요.

예를 들어 쿠폰 차감 후 200,000원 이상을 요구하는 결제 행사가 있다고 가정하면, 200,000원에서 6,000원을 뺀 194,000원은 그 조건에 못 미칩니다. 같은 가정에서 206,000원은 차감 후 200,000원이 됩니다. 이는 기준 금액 해석을 위한 예시이며 특정 카드·페이 행사의 실제 조건을 뜻하지 않습니다.

발급 전과 취소 전에 확인할 제한

  • 사용기한과 선착순 예산

    발급 후 7일 이내에 사용해야 합니다. 회원 ID당 1회 등록·사용 조건이며 만료 후 재발급이 제한됩니다. 남은 사용기한이 있어도 선착순 물량이나 예산이 소진되면 사용할 수 없습니다. 여행 출발일보다 결제할 시점에 맞춰 발급받으세요.

  • 취소·변경과 재사용

    예약을 취소한다고 사용한 할인쿠폰의 재발급이나 복원이 보장되지는 않습니다. 취소 화면의 환불 예상액과 할인쿠폰 복원 안내를 확인하세요. 할인쿠폰이 복원되더라도 사용기한과 예산 제한을 다시 확인해야 합니다.

취소 후 다시 예약해 3,000원을 더 할인받으려는데 취소 수수료가 5,000원이라면 오히려 2,000원을 더 지출합니다. 새 예약 가격, 취소 수수료, 재사용 가능 여부를 확인한 뒤 변경하세요.

할인코드 선택

마이리얼트립 10만원 투어에는 어떤 할인코드를 쓰나요?

위 5종 중에서는 할인코드: LINKPRICE2000을 선택하세요. 해외 투어·티켓에 적용 가능하면 100,000원에서 2,000원이 빠져 98,000원입니다.

마이리얼트립 해외 숙소 20만원에도 6,000원 할인되나요?

위 6,000원 할인코드는 해외 투어·티켓용입니다. 해외 숙소 200,000원은 숙소용 할인코드: LINKPRICESTAY3000이 적용되면 197,000원입니다.

마이리얼트립 할인코드는 신규 회원만 사용할 수 있나요?
