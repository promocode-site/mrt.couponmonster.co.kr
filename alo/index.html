누구에게 어떤 할인코드가 맞나요?

신규·기존 회원과 앱 이용자를 구분하세요

제공된 정보에는 신규 회원만 받는 혜택이나 앱 전용 할인 조건이 확인되어 있지 않습니다. 첫 주문이라는 이유로 추가 할인이 붙는다고 계산하지 마세요. 기존 회원도 계정 상태만으로 사용 가능 여부를 판단하기보다 주문별 적용 결과를 확인해야 합니다.

신규 회원
가입만으로 확정되는 별도 할인율은 미확인입니다.
기존 회원
개인별 자격과 상품 조건을 충족하는지 확인하세요.
앱 이용자
앱에서만 더 할인된다는 근거가 없으므로 웹과 앱의 혜택 차이를 전제하지 마세요.

놓치기 쉬운 조건 해석

미표기와 제한 없음을 구별하세요

최소 주문 금액이 미표기라는 안내는 소액 주문에도 반드시 적용된다는 뜻이 아닙니다. 최대 할인액 미표기 역시 무제한 할인을 보장하지 않습니다. 주문을 늘리기 전에 실제 결제 화면의 할인액이 예상과 일치하는지 확인하세요.

자격 조건은 할인율보다 먼저 확인하세요. 프로그램 할인은 인증이나 이용 주체 제한이 있을 수 있습니다. 입력이 가능하다는 사실과 적격 사용자라는 사실을 같은 의미로 해석하지 마세요.

미국 혜택과 한국 배송을 분리하세요

미국 기준 무료배송·무료반품 문구로 한국 주문의 비용을 0원 처리해서는 안 됩니다. 배송 국가를 바꾸면서 할인액이나 배송 옵션이 달라지는지 확인하고, 실제 배송비와 반품 조건을 별도로 읽으세요. 한국 배송에 대한 안내가 엇갈리는 할인코드는 배송지 입력을 마친 상태에서 다시 검증해야 합니다.

  • 게시된 만료 안내만으로 현재 사용 가능하다고 판단하지 마세요.
  • 적용 실패를 입력 오류로만 단정하지 말고 자격·상품·배송 국가 제한을 함께 확인하세요.
  • 해외 발송 여부와 세금 포함 여부가 확인되지 않은 주문에는 임의의 관세율을 더하지 마세요.

알로 할인코드 단계별 입력 방법

상품 선택부터 할인 적용까지 확인하세요

  1. 연결된 판매 화면에서 구매하려는 상품의 사이즈·색상과 정상가·세일가 표시를 확인하세요.
  2. 이용 자격이 필요한 할인코드는 해당 자격을 먼저 확인하세요. 비회원 입력 안내를 자격 제한을 우회하는 방법으로 이용하지 마세요.
  3. 장바구니에서 할인 가능한 상품 금액을 구분하고 결제 단계로 이동하세요.
  4. ‘할인 코드 또는 기프트 카드’ 입력란에 선택한 할인코드 문자열을 입력하고 적용하세요. 화면에 따라 입력란 명칭이 다를 수 있습니다.
  5. 입력란에 문자열이 남아 있는지만 보지 말고 주문 요약에 할인 항목과 차감 금액이 생겼는지 확인하세요.

배송지 입력 후 최종 합계를 검증하세요

  1. 실제 받을 국가와 주소를 입력하고 할인 상태가 유지되는지 확인하세요.
  2. 배송 방법별 비용과 세금 포함 여부를 읽고, 결제 통화와 결제수단의 청구 조건을 확인하세요.
  3. 상품 합계에서 할인액을 뺀 금액에 배송비와 표시된 추가 비용을 더해 최종 합계와 대조하세요.
  4. 주문 확정 후 확인 메일의 상품·할인액·배송지를 대조하고, 배송 및 반품 안내를 보관하세요.

적용 오류가 나면 할인코드를 연달아 입력하기 전에 오류 문구를 확인하세요. 할인 대상 상품을 바꿨거나 배송 국가를 변경했다면 이전에 표시된 할인액을 그대로 믿지 말고 주문 요약을 다시 확인하세요.

금액별 할인 계산

같은 상품 금액에서 25%와 20%를 비교하세요

금액별 비교는 모든 상품이 할인 대상이고 한도 제한 없이 적용된다는 계산용 가정입니다. 실제 판매가나 결제 견적이 아니며, 배송비·세금·결제 수수료는 포함하지 않습니다.

추가 비용이 붙으면 최종 절감액을 다시 계산하세요

계산용 상품가 20만원에서 25% 할인을 받아도 배송비가 가정상 1만5,000원 붙으면 합계는 16만5,000원입니다. 같은 상품의 20% 할인 후 금액 16만원에 배송비가 붙지 않는 경우보다 5,000원 더 지출합니다. 이는 실제 배송 정책이 아니라 비용 차이를 설명하는 예시입니다.
